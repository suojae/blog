아래 프롬프트를 복사해서 사용하면 된다.

---

```
/Users/jeon/Documents/Obsidian Vault 에 학습 노트를 작성해줘.

## 위치
- 기존 폴더 구조를 확인하고 알맞은 위치에 저장

## 작성 규칙

### 글 구조
- 제목: 핵심 주제를 한 문장으로
- 소제목: 제목과 다른 표현. "~하는 법" 같은 설명형이 아니라 "서버가 알림을 쏜다" 같은 서술형으로
- 시간 순서대로 흐르는 이야기 형태. 읽으면서 머릿속에 장면이 그려져야 함
- 이해하기 쉽게. 비유나 시각적 다이어그램 활용

### 내용
- 해당 주제만 좁게 설명하지 말고, 그것이 속한 전체 구조 안에서 이야기하기. "이 기술이 왜 여기에 있고, 앞뒤로 뭐가 연결되는지"가 보여야 함
- 특정 프로젝트에 종속되는 코드/변수명/파일명 제거
- 어떤 프로젝트에든 적용할 수 있는 범용 지식 위주로 작성
- 코드 예시는 핵심만 남기고 프로젝트 고유 구현은 빼기
- 삽질 기록은 포함하되 구체적 ID나 엔드포인트 대신 "왜 틀렸고 뭘 배웠는지"에 집중

### 옵시디언 연결
- 태그(#키워드)로 주제 분류
- [[]] 링크는 실제로 의미 있는 연결만. 억지로 관련 노트 섹션 만들지 않기
```
